# Контрольные вопросы

1. Как следует использовать команду chown, чтобы установить владельца группы для файла?
Команда: chown :группа файл
Пример: chown :developers script.sh

2. С помощью какой команды можно найти все файлы, принадлежащие конкретному пользователю?
Команда: find / -user имя_пользователя
Пример: find /home -user ivan

3. Как применить разрешения на чтение, запись и выполнение для всех файлов в каталоге /data для пользователей и владельцев групп, не устанавливая никаких прав для других?
Команда: chmod -R ug=rwx,o= /data

4. Какая команда позволяет добавить разрешение на выполнение для файла, который необходимо сделать исполняемым?
Команда: chmod +x файл
Пример: chmod +x my_script

5. Какая команда позволяет убедиться, что групповые разрешения для всех новых файлов, создаваемых в каталоге, будут присвоены владельцу группы этого каталога?
Команда: chmod g+s каталог
Пример: chmod g+s /shared_data

6. Необходимо, чтобы пользователи могли удалять только те файлы, владельцами которых они являются. С помощью какой команды можно это сделать?
Команда: chmod +t каталог
Пример: chmod +t /shared_uploads (это устанавливает sticky bit)

7. Какая команда добавляет ACL, который предоставляет членам группы права доступа на чтение для всех существующих файлов в текущем каталоге?
Команда: setfacl -R -m g:группа:r *
Пример: setfacl -R -m g:accounting:r *

8. Что нужно сделать для гарантии того, что члены группы получат разрешения на чтение для всех файлов в текущем каталоге и во всех его подкаталогах, а также для всех файлов, которые будут созданы в будущем?
Нужно установить ACL с рекурсией (-R) и default-правилом (-d).
Пример: setfacl -R -d -m g:mygroup:rX .

9. Какое значение umask нужно установить, чтобы «другие» пользователи не получали какие-либо разрешения на новые файлы?
Значение: umask 007
Пример: umask 007; touch newfile.txt (права для others будут ---)

10. Какая команда гарантирует, что никто не сможет удалить файл myfile случайно?
Команда: chattr +i myfile (устанавливает атрибут "неизменяемость")
