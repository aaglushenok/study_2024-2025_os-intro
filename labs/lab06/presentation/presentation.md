## Описание команд (1)

Опции команд: "cd" -L (обработка симв. строк до ..), -P (обработка обработка симв. строк после ..), -e (вывод ошибок). "mkdir" -m (установка режима работы с файлами), -p (создание родительской директории), -v (вывод сообщения для создания каждой директории), -z (установка секьюрити контекста SELinux). "pwd" -L (использование pwd из окружающей среды, даже если есть симв. ссылки), -P (избегание всех симв. ссылок):

![Описание команды cd](image/15.png){#fig:015 width=20%}

![Описание команды mkdir](image/16.png){#fig:016 width=20%}

![Описание команды pwd](image/17.png){#fig:017 width=20%}

## Описание Команд (2)

Опции команды rmdir: -p (удаление каталога, являющегося родительским), -v (вывод диагностики для каждой директории). Опции команды rm: -f (игнорирование несуществующих файлов и аргументов), -i (спрашивание разрешения перед каждым удалением), -I (спрашивание разрешения 1 раз при удалении более чем 3 файлов):
